Honest scope

No promises beyond the current MVP

Norbu is currently a directory prototype. It helps people orient themselves, compare profile information, open map searches, and leave local feedback.

No booking yet Appointments and calendar logic can be added later.
No medical recommendation The quiz only suggests a search direction, not a diagnosis.
No fake rankings Review scores are shown only when reviews actually exist.
